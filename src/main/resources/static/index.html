ZERO TABLE API

상권·매출·인구·점포·부동산 통계 데이터를 공개 API로 제공합니다.

  • Swagger UI — API 실행과 명세
  • 데이터 목록과 필드 사전
  • 최근 수집 현황
  • OpenAPI JSON · YAML

인증 없이 호출할 수 있습니다. 프론트엔드에서는 /api/v1/datasets/{dataset}/records로 수집 데이터를 조회하세요.

출처: 서울특별시·서울신용보증재단, 소상공인시장진흥공단, 한국부동산원. 데이터별 공식 출처와 필드는 데이터 목록에서 확인할 수 있습니다.
